Edit your site

Only someone with your private key (a GitHub token) can edit. Make it once:

  1. Open GitHub → new fine-grained token.
  2. Name it "site editor". Set the expiration as long as you like.
  3. Under Repository access, choose Only select repositories and pick your site repo.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.
